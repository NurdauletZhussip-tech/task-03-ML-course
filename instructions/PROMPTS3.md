# Промпты для Copilot: Task 3 (Midterm, Bank Marketing)

Это **черновик по README и данным**. Хендаута (Week 07, Canvas) у меня нет, поэтому метрика, формат файла предсказаний,
способ сохранения модели, пункты защиты и таблица баллов взяты как «уточнить». Первым делом положите текст хендаута
в `docs/TASK3.md` и сверьте им разделы «Факты» в `.github/copilot-instructions.md`.

Как работать: один промпт = одна ячейка. Запустили, посмотрели вывод, только потом следующий. Ссылка `#file:docs/TASK3.md` в каждом промпте.
Пункты **«Пишу сам»** (выбор модели, интерпретация, защита) формулируйте своими словами: на защите спросят.

## Где обычно ломается

| Ловушка | Что делает Copilot | Защита |
|---|---|---|
| `duration` | берёт как признак, а в test его нет | П1, П3 |
| `y` yes/no | считает accuracy, модель «всегда no» даёт ~0.887 | П2, П4 |
| `pdays=999` | трактует как число | П3 |
| утечка | `fit` препроцессинга на всех данных до CV | П3, П4 |
| порог | подбирает по test или не подбирает совсем | П5 |
| сохранение | сохраняет только модель без препроцессинга, другие версии | П7 |

## П4. Пайплайн и базовая модель
```
Построй ColumnTransformer: числовые — SimpleImputer(median) + StandardScaler; категориальные — OneHotEncoder(handle_unknown="ignore"),
unknown остаётся категорией. Собери Pipeline с LogisticRegression(max_iter=5000, class_weight="balanced", random_state=SEED).
Оцени StratifiedKFold(5, shuffle=True, random_state=SEED) метрикой из TASK3.md (+ ROC AUC и PR AUC как справочные), покажи mean ± std.
Всё preprocessing только внутри пайплайна.
```
